Welcome to the python directory of my master's thesis.

This code generates the flood indices (FI and PI) used in the panel data analysis.

If you have any questions regarding duplication, data retrieval, or about the process in general, you can reach me at nina.bilirossi@gmail.com

To run 01_flood_index.ipynb: download daily max precipitation data as per the instructions in the manuscript Appendix, or by using the GEE retrieval code (0_data_retrieval) on the GitHub. I save the files in the format: daily max pr era5/MAX_Precip_Wide_1995.csv.

To run 03_soil_moisture_antecedent.ipynb, you will also need to download soil moisture data. Instructions are in the file itself and in  0_data_retrieval.
